# Остров Умняша — релизы

Публичный манифест обновлений для приложения «Остров Умняша».

- `update.json` — версия, ссылка на APK и заметки. Приложение читает raw-файл с ветки `main`.
- APK лежат в [Releases](https://github.com/LittleGasik/kidsdevgame-releases/releases).

Исходники игры в этот репозиторий не кладутся.
